# Spider-Man: Into the Spider-Verse

![Movie](https://img.shields.io/badge/Genre-Animated%20Superhero-red)

## About the Movie

**Spider-Man: Into the Spider-Verse** is a 2018 animated film from *Sony Pictures Animation*. It follows Miles Morales, a teenager from Brooklyn who becomes Spider-Man and meets other Spider-People from different dimensions.
